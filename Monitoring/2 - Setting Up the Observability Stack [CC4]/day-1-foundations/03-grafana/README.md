## Quick Takeaway

Grafana:
- Connects to Prometheus (and other data sources)
- Creates beautiful dashboards
- Shows real-time metrics
- Lets you build custom visualizations
- Sends alerts

---

## Key Concepts

1. **Data Source** — Where the data comes from (Prometheus)
2. **Dashboard** — A collection of panels showing metrics
3. **Panel** — A single chart/graph/stat
4. **Query** — PromQL query to fetch metric data
5. **Variable** — Dynamic filter (e.g., select pod name)
